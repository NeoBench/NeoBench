NeoBench tools
==============

The tools drawer holds the program entries: files that start
something rather than being read.

  Clock        the dial.  The time, and the machine's own idea of it.
  Monitor      the two-bar system monitor: what the machine is doing
               with itself while you watch it.
  NeoText      the reader.  Plain text as written, a PDF with its
               text lifted out of the page, and a hex view of
               anything else, eight bytes to the line.
  NeoShell     the command line.  The NeoCommands, read against the
               store in the ROM and the hardware the probe found;
               `help` at the prompt lists them.

None of the four is on the start menu, so this drawer is how they are
started; a document chosen in Files still opens in NeoText whatever
you do.

NeoShell is also what boots in place of the desktop when Escape is
pressed during the three-second hold, and what Config/boot.cfg's
"failsafe = on" asks for on a machine kept for recovery.  Starting it
from this drawer leaves the desktop standing underneath it: `desktop`
closes the window again, and at boot it is the same word that lets the
compositor up.

Tools grows as the programs that belong in a toolbox are written:
the calculator is the next one on the list.
